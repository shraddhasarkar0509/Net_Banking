# Net_Banking System - Java Project

A Java-based Net Banking System project.
## Features
## User Module
- User Login / Registration
- Check Balance
- Fund Transfer
- Transaction History
- Profile Management
- Fixed Deposit(FD) - Create & View FD
- Recurring Deposit(RD)-Create & View RD
## Admin Module
- Admin Login
- View All Users
- Manage Accounts
- Manage FD & RD Requests

## Technologies Used
- Java (JSP / Servlet)
- HTML, CSS , JavaScript
- MySQL Database
- Apache Tomcat Server
- Eclipse IDE

## How to Run
1. Clone the repository
2. Import into Eclipse as Dynamic Web Project
3. Setup MySQL database
4. Configure Tomcat Server
5. Run on Server
